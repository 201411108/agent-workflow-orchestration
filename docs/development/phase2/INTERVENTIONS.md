# Phase 2 개입 기록

개입 1건 = 표 1행. **분류 1·2번(`컨텍스트 부족`, `역할 정의 결함`)에만** 상세 블록을
붙인다. 쓰는 노력을 Phase 3 입력이 나오는 곳에만 쓰는 의도적 마찰 설계다.

개입의 정의는 [README.md §4](./README.md), 분류 절차 Q1→Q2→Q3와 각 통과 조건은
[README.md §5](./README.md)에 있다. **순서대로 묻고 먼저 맞는 곳에서 멈춘다.**

- `컨텍스트 부족` 통과 조건: 답이 있던 경로와 줄, 또는 핸드오프 필드를 적어야 한다
- `역할 정의 결함` 통과 조건: **대체 문장을 기록 시점에 실제로 써야 한다**
- `판단 필요`: 두 조건이 모두 참이고 둘 다 기록돼야 한다

`재현` 플래그(`반복` | `1회`)는 직교다. 이것이 없으면 모델 변동이 역할 정의 결함으로
세탁된다.
